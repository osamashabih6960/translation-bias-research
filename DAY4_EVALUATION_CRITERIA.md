
# Day 4 — Translation Evaluation Criteria

## 1. Meaning Preservation

- 2 = Meaning preserved
- 1 = Partial meaning preserved or minor information omitted
- 0 = Major meaning change or incorrect translation
- U = Cannot determine from available context

## 2. Unsupported Gender Information

- 1 = Translation introduces gender information not supported by the source or available context
- 0 = No unsupported gender information identified
- U = Cannot determine because the source or context is ambiguous

## 3. Additions and Omissions

Record whether the English translation:
- Adds information absent from the source
- Omits important information from the source
- Changes a relationship, action, or descriptive detail

## 4. Evidence

For every candidate issue, record:
- Row ID
- Bengali source
- English translation
- Issue category
- Explanation
- Reviewer decision

## 5. Review Rules

- Do not treat every gendered English word as bias.
- Bengali grammar and context may convey information that is not obvious from an isolated word.
- Do not label a translation as biased without supporting evidence.
- Use U when the available context is insufficient.
- Automatic flags are candidates for review, not confirmed errors.

## 6. Pilot Evaluation

Start with a small sample of translation pairs.
Review each pair manually before calculating confirmed issue rates.
Record the number reviewed and the number confirmed in each category.
